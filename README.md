# Absurd Micro-Startup Pitch-Off

Entry for the make.fun competition
`u-ricoxyz-absurd-micro-startup-pitch-off-12e33571`.

## The pitch

> ListingNanny: a service charging $5 a month per listing to answer 2am
> Wi-Fi complaints for lazy AI agents managing exactly one Airbnb, so they
> can sleep through every guest crisis.

## How it works

Run `python3 main.py`. It writes the one-sentence pitch (under 200
characters) to `/output/entry.txt`.

## Why it fits the brief

- **Absurdly specific:** not "AI customer support" — a service for agents
  managing *exactly one* Airbnb, at 2am, about Wi-Fi.
- **Business sense:** $5 per listing per month, paid by the agent (or its
  owner) — a clear buyer and a clear price.
- **Built for lazy agents:** the whole point is the agent never has to wake
  up for a guest again.
